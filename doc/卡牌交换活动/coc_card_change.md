# 卡牌交换活动

新增一个公开页面，无需登录也能使用，地址栏需携带群组编号，此功能为辅助部落成员进行卡牌交换。

## 1. 页面与列表
1. 数据按列表展示，每行左边为成员名称，右边为多余卡牌、缺失卡牌，再右边为操作。
2. 操作包含：编辑、删除；删除仅群主或群组管理员登录后展示（参考现有其他功能的权限逻辑）。
3. 在页面顶部展示"新增成员"和"查找交换对象"按钮。

## 2. 新增 / 编辑成员
4. 新增成员：包含成员名称，下拉选择部落，选择多余卡牌、缺失卡牌。
5. 编辑页面同新增。编辑权限：任何人都能编辑任意成员（参考现有其他功能的业务逻辑）。
6. 部落：以 URL 的群组编号为准，部落为必选，仅做标识，采用现有部落下拉选择功能。
7. 一个成员可添加多张多余卡和缺失卡（成员与卡牌为一对多关系）。

## 3. 删除
8. 删除为软删除（置位删除标记），与唯一性约束（忽略已删除数据）保持一致。按成员 id 操作。

## 4. 查找交换对象
9. 选择当前用户：从本群组内已录入的交换成员（成员表数据）中选择一个，非系统登录用户。
10. 单选项选择：互利互惠、单方受益，默认选中互利互惠。
11. 选择"一键查找"，匹配前置条件为**同一个卡牌分类中**，且按**卡牌名称精确匹配**：
    - 数量规则：多余卡数量 > 2 才视为"多余"；卡牌不存在或数量为 0 视为"缺失"。
    - 互利互惠：需同时满足——存在自己缺少且对方多余的卡牌（X），存在自己多余且对方缺少的卡牌（Y）。
    - 单方受益：存在自己缺少且对方多余的卡牌（X），且己方存在多余的卡牌即可；对方得到的是己方多余卡中同卡牌分类下任意一张（不一定是对方缺失的）。
12. 查找结果展示：弹出列表，按**对方名称**分组（外层），组内按**卡牌分类**分组（内层），每组列出多对"己方换出 / 对方换出 + 对方名称"。

## 5. 匹配示例
假设：我多余 X、Y、Z，缺 M、N；对方多余 X、M、N，缺 Y、Z。

- 选互利互惠（我缺且对方多：M、N；我多且对方缺：Y、Z）：
  - 己方得到 M —— 己方换出 Y 或 Z
  - 己方得到 N —— 己方换出 Y 或 Z
- 选单方受益（我缺且对方多：M、N；我方多余任意一张回赠）：
  - 己方得到 M —— 己方换出 X 或 Y 或 Z
  - 己方得到 N —— 己方换出 X 或 Y 或 Z

## 6. 数据表结构
13. 数据新建表存放：卡牌交换成员表、卡牌交换成员卡牌表。

### 卡牌交换成员表
| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| groupNo | 群组编号（取自 URL） |
| 成员名称 | 成员名称 |
| 所属部落 | 部落（采用现有部落下拉，仅标识） |
| 创建人 | 创建人 |
| 创建时间 | 创建时间 |
| 修改人 | 修改人 |
| 修改时间 | 修改时间 |
| 删除标记 | 软删除标记 |

### 卡牌交换成员卡牌表
| 字段 | 说明 |
| --- | --- |
| id | 主键 |
| 成员id | 关联成员表 id |
| 卡牌名称 | 卡牌名称（精确匹配键） |
| 卡牌分类 | 圣水兵、黑油兵、超级兵、建筑大师基地兵（字典：card_category） |
| 卡牌icon | 卡牌图标 |
| 数量 | 仅建表时使用，业务处理暂不需要；存在即按多余，不存在即按缺失 |
| 类型 | 多余 / 缺失（字典：card_type） |
| 创建人 | 创建人 |
| 创建时间 | 创建时间 |
| 修改人 | 修改人 |
| 修改时间 | 修改时间 |
| 删除标记 | 软删除标记 |

14. 成员唯一性：按群组编号(groupNo) + 成员名称 确认唯一；唯一性校验忽略已删除（删除标记置位）的数据。

## 7. 卡牌数据来源
15. 卡牌图标数据可放进前端资源（icon 目录）。
16. 卡牌分类、类型(多余/缺失)复用现有系统字典；部落采用现有部落下拉功能。字典类型 code：
    - card_category：卡牌分类（圣水兵、黑油兵、超级兵、建筑大师基地兵）
    - card_type：卡牌类型（多余、缺失）

## 8. 数据隔离
17. URL 群组编号需做存在性校验；群组不存在时页面提示"群组不存在"，且不展示列表、不允许新增。

## 9. 接口清单（小驼峰命名，前后端一致）
18. 作为单独功能开发，不影响现有功能。接口路径统一小驼峰：
    - GET  `/cardExchange/members?groupNo=`            查询本群组交换成员列表
    - POST `/cardExchange/member/save`                 新增 / 编辑成员（含卡牌明细）
    - POST `/cardExchange/member/delete`               软删除成员（按成员 id）
    - POST `/cardExchange/findMatch`                   查找交换对象（入参：当前成员 id、匹配类型 互利互惠/单方受益）
    - GET  `/cardExchange/group/check?groupNo=`        群组存在性校验
